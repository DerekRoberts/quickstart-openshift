## Prisma migrations (Prisma ORM 7+)

This repository uses **Flyway** for database schema migrations (see `/migrations/sql`).

Prisma is used as an ORM layer and is configured for Prisma 7+ via `backend/prisma.config.ts`.
If you choose to use Prisma migrations in your fork, this folder is the default location configured in `prisma.config.ts`.
